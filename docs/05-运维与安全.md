# 05 运维与安全

> 部署完成之后的日常：看日志、备份、升级、加固、多实例、监控。

## 5.1 日志排查

```bash
# 实时跟随（最常用）
journalctl -u asf -f --no-pager

# 只看关键事件
journalctl -u asf -n 200 --no-pager | grep -iE 'logged on|farming|badge|2FA|error|warn'

# 按时间段
journalctl -u asf --since '30 min ago' --no-pager -o cat

# 反代服务
journalctl -u steam-proxy -n 50 --no-pager -o cat
```

| 关键日志 | 含义 |
|----------|------|
| `Successfully logged on as 7656119xxxxxxxxxx` | 登录成功 |
| `Checking first badge page...` | 正在读徽章页（社区通）|
| `Farming ... (x/y cards remaining)` | 挂卡中 |
| `We don't have anything to farm` | 该账号已挂满（正常）|
| `Please enter 2FA code` / `RequiredInput` | 等令牌验证码 |
| `Request failed` | ❌ 社区访问失败（去 03 章）|

自动清理 systemd 日志：

```bash
journalctl --vacuum-time=7d     # 或编辑 /etc/systemd/journald.conf 设 SystemMaxUse=200M
```

## 5.2 开机自启与重启策略

```bash
systemctl enable --now asf steam-proxy     # 自启
systemctl is-enabled asf                    # 检查
```

推荐单元里始终保留：

```ini
Restart=always
RestartSec=10
```

> 含义：进程退出（含被 OOM 杀）后 10 秒自动拉起。挂卡服务必须这样，否则半夜挂了没人知道。

## 5.3 备份与恢复

**只需要备份 `/opt/asf/config`**（含账号配置与登录凭据；程序目录可随时重下）。

```bash
tar czf /root/asf-config-$(date +%F).tgz -C /opt/asf config
```

建议 cron 每天备份、保留 7 份：

```bash
cat > /etc/cron.daily/asf-backup <<'EOF'
#!/bin/sh
D=/root/asf-backups; mkdir -p $D
tar czf $D/asf-config-$(date +%F).tgz -C /opt/asf config
find $D -name 'asf-config-*.tgz' -mtime +7 -delete
EOF
chmod +x /etc/cron.daily/asf-backup
```

**恢复**：

```bash
systemctl stop asf
tar xzf /root/asf-backups/asf-config-2026-01-01.tgz -C /opt/asf
systemctl start asf
```

> ⚠️ 配置里含 Steam 密码和登录令牌（`.db`），备份文件**不要放公开网盘/仓库**。建议 `chmod 600`。

## 5.4 升级 ASF

```bash
systemctl stop asf
cp -a /opt/asf/config /opt/asf/config.bak          # 先备份配置
# 重新下载并覆盖程序文件（配置不会被覆盖）
#   重复 02 章的下载 + python3 解压步骤即可
chmod +x /opt/asf/ArchiSteamFarm
systemctl start asf
journalctl -u asf -n 20 --no-pager | grep -i version
```

> 升级后若插件不兼容（第三方插件需匹配 ASF 大版本），把旧插件移出 `plugins/` 再逐个加回。

## 5.5 IPC 安全（重要）

IPC 控制台可以**操作你的 Steam 账号**（加/删机器人、挂机、2FA 等），务必按下面加固：

| 措施 | 做法 |
|------|------|
| 设强密码 | `ASF.json` 的 `IPCPassword` |
| 只监听本机 | `IPC.config` 里 `http://127.0.0.1:1242`（默认建议）|
| 用 SSH 隧道访问 | `ssh -L 1242:127.0.0.1:1242 root@IP` → 浏览器开 `http://localhost:1242` |
| 不要公网暴露 | 若必须公网：至少强密码 + `ufw allow from <你的IP>` 限制来源 |
| 云安全组 | 只在控制台按需放行，最小化开放端口 |

**从公网收回到仅本机**（如果之前暴露过）：

```bash
# 1) 改监听
sed -i 's|http://\*:1242|http://127.0.0.1:1242|' /opt/asf/config/IPC.config
systemctl restart asf
# 2) 删掉防火墙放行
ufw delete allow 1242/tcp
```

### 跨机管理：SSH 隧道常驻（systemd）

需要在 A 机访问 B 机的 ASF 时，用一条常驻隧道，比暴露端口安全得多：

```ini
# /etc/systemd/system/asf-tunnel.service  (放在 A 机)
[Unit]
Description=SSH tunnel to remote ASF IPC
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/usr/bin/ssh -N -i /root/.ssh/id_ed25519_tunnel \
  -o StrictHostKeyChecking=accept-new -o ServerAliveInterval=30 -o ServerAliveCountMax=3 \
  -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:1242:127.0.0.1:1242 root@<B机IP>
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
ssh-keygen -t ed25519 -f /root/.ssh/id_ed25519_tunnel -N ""
ssh-copy-id -i /root/.ssh/id_ed25519_tunnel.pub root@<B机IP>
systemctl enable --now asf-tunnel
curl -s -o /dev/null -w '%{http_code}\n' -H 'Authentication: <IPC密码>' http://127.0.0.1:1242/api/asf
```

## 5.6 多实例部署（多账号/多客户隔离）

同一台机器跑多套 ASF（例如"自己的账号"和"客户的账号"完全隔离）：

```bash
cp -a /opt/asf /opt/asf-shop            # 复制一套（含程序）
rm -rf /opt/asf-shop/config/*           # 清空配置
mkdir -p /opt/asf-shop/config
# 写独立的 ASF.json / IPC.config（端口换成 1243）
```

```ini
# /etc/systemd/system/asf-shop.service
[Unit]
Description=ArchiSteamFarm (Shop)
After=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/asf-shop
ExecStart=/opt/asf-shop/ArchiSteamFarm --path /opt/asf-shop --system-required
Restart=always
RestartSec=10
MemoryMax=600M
OOMPolicy=stop

[Install]
WantedBy=multi-user.target
```

要点：
- **IPC 端口必须不同**（1242 / 1243 …）
- 每套独立 `MemoryMax`，避免互相拖累
- 客户账号建议独立实例 + 独立目录，出问题不互相影响

## 5.7 内存与性能控制

| 手段 | 命令/配置 |
|------|-----------|
| 限制单服务内存 | systemd `MemoryMax=` / `MemoryHigh=` |
| 加 swap 兜底 | `fallocate -l 2G /swapfile && mkswap /swapfile && swapon /swapfile` |
| 降低调度优先级 | `Nice=15`、`IOSchedulingClass=idle` |
| 看谁在吃内存 | `ps -eo pid,rss,cmd --sort=-rss \| head -8` |
| 看服务内存 | `systemctl show -p MemoryCurrent asf` |

> 硬经验：**Steam 客户端（含 CEF）是内存大户（1–1.2GB）**，ASF 反而很小。
> 如果要在同一台机器上跑「客户端 + 多实例 ASF」，请直接上 4G 内存。

## 5.8 简单监控告警

```bash
# /etc/cron.d/asf-check : 每 10 分钟检查服务与掉卡状态
*/10 * * * * root /usr/local/bin/asf-check.sh
```

```bash
#!/bin/bash
# /usr/local/bin/asf-check.sh —— 服务挂了自动拉起；发现网络异常写日志
if ! systemctl is-active --quiet asf; then
  systemctl restart asf
  logger -t asf-check "ASF 不在运行，已重启"
fi
if ! curl -sS -o /dev/null --max-time 8 https://steamcommunity.com/; then
  logger -t asf-check "社区反代异常，请检查 steam-proxy / 上游 IP"
fi
free -m | awk '/Mem:/ {if ($7 < 100) print "内存告急: 可用 " $7 "MB"}' | logger -t asf-check
```

## 5.9 安全检查清单

- [ ] `IPCPassword` 是强密码，且没有出现在任何公开仓库/聊天记录里
- [ ] IPC 仅监听 `127.0.0.1`（或严格限制来源 IP）
- [ ] `ufw` 已启用，只放行必要端口（22 必留）
- [ ] 云厂商**安全组**同样最小化开放
- [ ] `/opt/asf/config` 权限收紧：`chmod 700 /opt/asf/config`（内含账号密码）
- [ ] 备份文件加密或离线保存
- [ ] 服务器 SSH 已禁用密码登录（改用密钥）
- [ ] 定期 `journalctl --vacuum-time=7d` 防止日志写满磁盘
